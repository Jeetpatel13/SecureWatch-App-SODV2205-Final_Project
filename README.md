# SecureWatch: Cybersecurity & Vulnerability Explorer
 
A React Native (Expo) mobile app for discovering, searching, and understanding publicly disclosed software vulnerabilities (CVEs) using live data from the National Vulnerability Database (NVD) API.
 
Final Term Project, Mobile Application Development with React Native I (SODV2205-02), Bow Valley College.
 
## Project Description
 
SecureWatch helps developers, IT students, and cybersecurity beginners explore real vulnerability data on their phones. Users can browse recently published CVEs, search by keyword or CVE ID, filter by severity, view full details, and save vulnerabilities for later. All data comes from the NVD API in real time, and the app uses no local database.
